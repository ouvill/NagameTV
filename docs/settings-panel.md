# 設定画面

Penpotの「FluTV Redesign / 06 Settings」を参照し、設定をウィンドウ全体に表示する。
左にカテゴリ、右に設定内容を置き、配色・余白・選択行・角丸をデザイン案に合わせた。
項目は実装済みの機能に合わせ、以下に整理している。

スクリーンショットの仕様と検証結果は[作業リスト](screenshot-worklist.md)を参照する。

| カテゴリ | 内容 |
| --- | --- |
| 接続 | MirakurunのURL、保存して接続、入力方法と変更時の影響、接続エラー、起動時の自動再生 |
| 表示 | 表示言語、字幕の表示／非表示、スクリーンショットの保存先・保存形式・圧縮設定・フォルダーを開く |
| コメント | 実況の有効化、映像への重ね表示、文字の大きさ（14〜72px）・濃さ・流れる速さ、ドロップシャドウ、送信キー |
| ショートカット | 現在の送信キー、視聴操作のキー一覧 |
| 診断 | 動画統計、ログフォルダー、動作状況とリソースの使用状況 |
| リモート操作 | 有効／無効、待受IP・ポート、受付状態・エラー、接続先 |

設定内容だけを縦にスクロールし、カテゴリと下部の「視聴へ戻る」は固定する。
内容が収まらない場合はスクロールバーを常時表示する。
ウィンドウ幅1200px未満または高さ700px未満では余白と左メニューを縮め、
アプリの最小サイズ900×560にも対応する。上部のウィンドウ操作は引き続き利用できる。

## 反映とエラー

接続先とリモートのIP・ポートは明示的な適用時に、それ以外は操作時に反映し、設定画面を閉じると既存の保存処理を呼ぶ。
自動再生の選択は操作時に`autoplay`キーへ保存し、次回起動から反映する（初期値OFF）。
保存した選択局が一覧にない場合は、既存の選局規則に従って最初の局を使う。
`MIRAKURUN_AUTOPLAY`の明示指定はその起動だけ優先し、保存済みの選択は変更しない。
スクリーンショットの保存先は`ScreenshotDirectory`の既定／カスタムで表す。
保存ファイルの`screenshot_directory = ""`はシステムのピクチャフォルダー内の
`mirakurun-viewer`を意味し、カスタム値は検証済みの絶対パスとして保存する。
変更時にはディレクトリーの作成・書き込み可能性を確認し、失敗した場合は以前の設定を保持する。
「フォルダーを開く」は必要ならディレクトリーを作成してファイルマネージャーを開く。
保存完了の通知にLucideのfolder-openアイコンを置き、その画像を保存したフォルダーを開ける。
保存中に設定を変えても、通知先は変わらない。連続した成功は同じ保存先ごとに件数をまとめる。
失敗通知は次の成功で消さず、失敗の表示後に成功通知を出す。
通知は6秒で消え、マウスを重ねている間やボタンにキーボードフォーカスがある間は表示を保つ。

保存形式は地デジ・BS・CSと同じ切り替え部品からPNG（標準）／JPG／WebPを選ぶ。
形式の特徴とパラメーターの説明を分け、選択中の形式の設定だけを表示する。
PNGの圧縮レベルは0〜9（初期値6）、JPGの画質は1〜100（90）、WebPの画質は1〜99（90）。
WebPは「画質を落とさずに保存」も選べ、この場合は画質の入力を隠す。
QtのWebPプラグインは品質100を可逆保存に使うため、非可逆の画質指定は99までとする。
形式は`screenshot_format`、形式別の数値とWebPの保存方式は`screenshot_options`へ保存する。
切り替え・再起動で値を復元し、以前の設定に指定がなければ上記の初期値を使う。

撮影時には、Qtが表示した元映像と同じ描画時点の字幕・コメントを固定する。
映像はデインターレース後・ウィンドウ用の縮小前のフレームを使い、画素比を補正する。
字幕・コメントは表示中の位置・書体・大きさを保存画像の解像度へ換算して描画する。
非表示の文字、映像の外の黒帯、操作ボタンや通知は含めない。
GPUからの画像取得、文字の合成、圧縮、ファイル書き込みは保存ワーカーで行う。
保存待ちでも撮影を受け付け、2件ずつ並行保存する。
待機・実行中の合計は32件、保持する画像の見積もりは256MiBまでとし、上限時は短い案内を表示する。
保存先・形式・パラメーターも撮影時に固定し、保存時に書き込み可能性を再確認する。
エンコード成功後に、撮影時刻を使う重複しないファイル名で公開する。
受理済みの保存は再生停止後も続け、終了時には映像・Qtの資源を解放する前に完了させる。
[取得方法・検証・制約](screenshot-worklist.md)も参照する。
言語の読み込みに失敗した場合はエラーを表示し、元の選択を維持する。
起動時の機能制限、字幕・実況の状態、設定保存とログフォルダーのエラー表示も維持する。
スイッチに変更の影響を添え、起動オプションで変更できない場合は理由を表示する。
実況の送信キーは「コメント」でCtrl + Enter（標準）／Enterから選ぶ。
Enterを選んだ場合もCtrl + Enterは利用できる。

字幕の表示／非表示は視聴者向けの設定で、「表示」と再生バーから同じ処理を呼ぶ。
表示の切り替えで再生を再接続せず、選択は操作時に保存して次回起動時に復元する。
字幕処理とEPG取得は通常起動では常に有効にし、停止は開発用の`--features`で指定する。
両機能の停止スイッチはメモリー調査用に設けたものなので、通常の設定画面から除いた。
`Text.NativeRendering`に伴うメモリー増加は`Text.QtRendering`への変更で解消済みという
開発経緯に合わせた整理であり、今回描画方式を変更したものではない。

保存形式は既存の`subtitles_enabled`キーを維持し、内部では`show_subtitles`という
表示選択として扱う。既存のON/OFFを引き継ぎ、初期値は表示OFF。
古い`epg_enabled`値は互換用のデータとして保持するが、通常起動の機能停止には使わない。
`--features`起動は引き続き通常の設定を読み書きしない。

生のエラー詳細は「詳細を表示」で開き、最初は影響と次の操作を短く案内する。
接続欄の編集と設定画面の再表示では過去の入力エラーを隠す。
チャンネル未選択時は選択を案内し、実際に未対応の局を選択した場合と区別する。

URLは「保存して接続」または入力欄のEnterで反映する。
接続要求が受理されたら設定画面を閉じ、拒否されたら画面を残して状態を表示する。
要求の受理は接続完了を意味しない。取得中の重複要求は受け付けない。
未確定のURLはカテゴリ移動中は保持し、設定画面を開き直すと現在の接続先へ戻す。

## 実装と検証

`SettingsPanel.qml`が構成とバックエンド接続を担当する。
行全体で操作できるスイッチ、スライダー行、言語選択は
`SettingsToggle.qml`、`SettingsSlider.qml`、`SettingsChoice.qml`に分けている。
旧`SettingsDrawer.qml`とそのテストは置き換えた。

  開発用起動オプションによる制限、送信キー選択、画面下部での選択メニュー、
  エラー詳細の開閉、接続の受理・拒否、言語エラー時の復元、スクロールと折り返しを確認。

  表示選択の保存・復元、通常起動と開発用許可リストの独立性を含む。
- 設定画面の翻訳参照58件とプレースホルダー、qmllint、Rustの書式・差分検査が成功。
