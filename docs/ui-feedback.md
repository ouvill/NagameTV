# 操作への反応

アプリ全体の設計・レビュー基準は[UIデザイン方針](ui-design.md)を参照する。
この文書は各部品の振る舞いと調整・検証の記録を扱う。

再生バーと設定画面を中心に、押している間の変化と短い移動を加えた。
アイコン・文字ボタン・チャンネルカードは背景と内容だけを縮め、クリックできる範囲を固定する。
操作は従来どおりクリック時に反映し、アニメーションの終了を待たない。

| 操作 | 見た目の反応 |
| --- | --- |
| 再生バーのボタン | ホバーで少し拡大し、押すと沈み、離すと戻る |
| 設定・プレイヤー・サイドパネルのスイッチ | 押している間につまみが少し伸び、切り替えに合わせて移動する |
| スライダー | つまむとつまみと軌道が太くなり、値は操作に直接追従する |
| 設定カテゴリ | 選択枠が移動し、内容が短く滑り込む |
| 選択メニュー | 矢印が回転し、メニューが軽く開く |
| チャンネルカード | ホバーで枠と背景を強調し、押すと少し沈む |

押し込みは65ms、色の変化は100〜140ms、戻りや移動は150〜180msを中心にしている。
既存のチャンネル移動やパネル開閉の速度に合わせ、操作間で手応えを揃える。
アニメーションは状態変更で始まって終了する。装飾用の常時タイマーや描画レイヤーは追加しない。
設定を素早く切り替えても選択状態は即時に更新し、閉じる際に内容の移動を完了させる。

スイッチは`ToggleSwitch`に外観と操作を集約し、`SettingsToggle`は説明文付きの行として継承する。
大きさ・色・押し込み・ホバー・無効時の表示を全画面で揃え、Space操作とキーボードフォーカス表示にも対応する。
縮めるのはインジケーターだけで、クリック範囲は固定する。設定行はラベル部分からも切り替えられる。

再生設定はサイドパネルの先頭タブに配置する。動画統計や弾幕設定の変更でもパネルを保持し、
高さが足りない場合は内容をスクロールする。閉じる操作と下部の3タブは常に表示する。

2026-09-19のPenpot「NagameTV · デザイン更新」のライブ画面と共通部品に合わせ、
下部は左に音量とLIVE、中央に再生操作、右にチャンネル・投稿・撮影・表示操作・サイドパネルを置く。
参照ボードは「共通部品 / プレイヤー右下操作」「共通部品 / Liveボタン」、
「サイドパネル / 再生設定」「サイドパネル / 番組情報・実況接続」と各900×560版。
映像幅960px以上では右側の全操作、740〜959pxでは字幕・弾幕・全画面を「…」へまとめる。
740px未満では右側を32pxのボタンにし、中央の42pxの再生操作と1段の配置を保つ。
最小ウィンドウ900×560ではサイドパネルを320pxとし、映像幅580pxを確保する。

音量ボタンのホバーで音量スライダーと音声選択を開き、クリックはミュート切り替えに使う。
キーボードでは音量ボタンの上下キーでスライダーへ移動する。
LIVE復帰は音量の右へ集約し、再生が受信端から2.5秒以内なら赤い中心のradio、
一時停止・シーク・それ以上の遅延では白いradio-offを表示する。2.5秒はデコードの遅延を許容する表示上の目安。
録画ではLIVE・チャンネル選択・投稿を表示しない。

ライブのタイムラインは「タイムシフト / 3番組をまたいで視聴」と900×560版に合わせ、
番組名をバーの上、区間の時刻を下へ配置する。視聴中は白い太字、放送中は接頭辞で区別し、
ライブ復帰で番組区間の位置を動かさない。寸法と狭い幅での省略規則は
[ライブのシークバー・表示モデル](live-timeline-design.md#penpotの番組跨ぎデザイン2026-09-19)に記載する。

変更箇所は`IconAction`、`TextAction`、`ThemedSlider`、`ToggleSwitch`、`SettingsToggle`、
`SettingsChoice`、`SettingsPanel`、`ChannelBrowser`、`SidebarChannels`。
音量の保存タイミングやコメントの送信条件など、バックエンド呼び出しの契約は変えていない。

検証記録はGit対象外の`benchmark/settings-panel-20260913/interaction-*`に保存する。
