# ながめTVのスクリーンショット

画像は1440×810の実際のアプリ画面です。2026-09-21の最新版で撮影しました。
局名・ロゴ・番組編成は撮影用の架空のデータで、サンプル映像の番組名は作品名を表示しています。
ローカルの撮影用配信元と、下記の再配布可能な映像を使用しました。

## 視聴画面

映像に番組名・放送時間・再生操作を重ねて表示します。

![視聴画面](live.png)

## チャンネル一覧

放送種別を切り替え、放送中・次の番組を見ながら選局できます。

![チャンネル一覧](channels.png)

## 番組表

複数のチャンネルを並べ、今日から7日分の番組を確認できます。

![番組表](guide.png)

番組を選ぶと詳細が開き、放送中ならその番組へ移動できます。

![番組詳細](guide-details.png)

## TS録画の再生

ローカルのTSファイルを開き、一時停止・シークできます。画像は一時停止中です。

![録画の再生](recording.png)

## 素材とクレジット
