## 通常ビルド

弾幕のON/OFFによらず、サイドバーの実況ページは弾幕の制御と接続状態だけを表示する。
コメント一覧の表示部品は通常版のQML登録・リソースに組み込まず、設定・ページ切替・再生成でも表示しない。
受信コメント本文を、最新1件だけなどの形でサイドバーへ表示する代替機能も設けない。
内部のコメント履歴・受信・投稿・再生同期は維持する。内部モデルの保持と一覧の画面表示を区別する。
制御は表示方式、配置方式、文字サイズ、透明度、速度、影、弾幕ON/OFFを含む。
既存の設定画面・再生設定と同じ設定値を操作する。弾幕OFF時も次回の表示設定を変更できる。
NX-Jikkyoの番組名・接続状態はプレーンテキストで表示し、コメント機能が無効でも状態は読めるようにする。

弾幕の表示領域は、映像の表示アスペクト比（ピクセルアスペクト比を含む）から計算した実映像矩形と一致させる。
16:9固定にはしない。映像情報未取得中は映像外へ仮表示せず、情報取得後に表示を開始する。
横長・縦長ウィンドウ、4:3映像、サイドバー開閉、全画面、再生元変更に追従する。
レイヤー外にある文字・影・回転後の部分はクリップする。

表示方式は排他的なenumで表し、従来の横流れと、新しい「噴水」（内部値 `pop`、放物線表示）を選べる。
既存設定の移行時は横流れを選ぶ。表示方式を切り替えた時は既存の表示を清掃し、異なる運動を混在させない。

配置方式もenumで表す。通常は順送りの分散配置を使い、ランダム配置も選択できる。
コメント同士の矩形・距離・相対速度・追いつき・将来の重なりを比較しない。
行や投入口は順番または再現可能な乱数で決定し、一定時間当たりの新規投入数を制限して密度を抑える。
混雑した場合は遅延して流さず見送る。これは重なりを保証して排除する方式ではなく、時に重なりを許す。
横流れの速度は文字幅から決めず、表示領域とユーザの速度設定から決める。
文字幅は消滅判定・クリップ・固定コメントの中央寄せ等にだけ使用する。
`ue` / `shita` は横流れモードでは固定表示を維持し、ポップモードではすべて同じ放物線表示に統一する。

## ポップの動き

コメントが映像の下から飛び込み、上昇が緩み、頂点を越えて下に落ちる。
弾道は時間から直接計算する。横方向は一定速度、縦方向は上向き初速と下向き加速度による放物線とする。
下端の複数の投入口へ分散し、入射角・初速・到達高さに控えめなばらつきを持たせる。
文字の傾きは±20度以内。読みやすさのため回転し続けず、コメントごとの傾きを保つ。
勢いよく入り、頂点付近で読め、落下時に自然に薄くなる動きにする。
乱数はコメントの安定した識別情報から生成し、シーク復元でも同じ軌道になるようにする。
画面寸法と文字サイズが変わっても、時刻・残り寿命を保ち、有限の座標で描画する。

再生に同期するコメントは映像時計を使い、一時停止で静止する。
シーク時は経過時間を使って途中の座標・傾き・透明度を復元し、遅れて届いた計測結果で旧表示を復活させない。
直接受信モードも同じ運動モデルを使う。スクリーンショットには表示時点の傾き・位置・透明度を反映する。

## 評価専用ビルド

通常ビルドから独立した明示的なCargo featureとCMake optionで、次を個別に評価できるようにする。

- `evaluation-comment-list`: サイドパネルの実況一覧を復元し、弾幕との併用も可能にする。関連: JP7080382 / JP7277651 / JP7153786 / JP7852687。
- `evaluation-wide-comments`: 従来の映像部品全幅を使う表示領域。関連: JP4734471。
- `evaluation-collision-layout`: 従来の衝突・追いつき回避による配置を選択可能にする。関連: JP4695583 / JP6526304 / JP7178462。
- `evaluation-legacy-comments`: 上記をまとめて有効にする。

これらは配布目的ではなくローカル比較評価用。既定で無効にし、パッケージ作成経路では有効化を拒否する。
通常版の設定ファイルから評価専用の配置方式を指定しても有効化できないよう、境界で検証する。
コード中に無効化・分岐の理由、特許番号、予想満了日と未確認事項を記載する。
JP4695583 / JP4734471は2026-12-11、その他上記候補は2027-03-02が公開情報上の予想満了日。
年金・訂正・消滅・延長等の原簿確認が未了なので、「その日まで有効」と断定しない。

## 検証

Rustコアでは投入量、各配置方式、通常版で評価方式が使えないこと、弾道の頂点・落下・寿命、
乱数の再現性、シーク・停止・リサイズを検証する。既存アルゴリズムの試験は評価用featureで維持する。
設定の移行と不正値、Qt通知時の整合、サイドバー一覧の通常版での不生成、映像矩形の算出とクリップも確認する。
通常版では一覧QMLのリソース不存在、弾幕ON/OFF・ページ切替・パネル再生成後の制御表示を確認する。
評価版では一覧の生成・履歴更新・状態の追従を確認する。両版とも製品モジュールの読み込みを確認する。
GUIはリポジトリーの専用セッションだけを利用し、GPU・表示・音声を検出・検証してから実行する。
必要資源が無い場合は依存する試験を止め、機器不要の実装・検証結果と未完了理由を記録する。

## 実装値と評価手順

通常配置の投入上限は、表示可能行数の1/3を1〜6件/秒に制限した値。
時間枠ごとに先着1件を採用する。文字の幅、他コメントとの距離・相対速度・占有行は比較しない。
横流れは通常5秒（全画面8秒）で映像幅を移動する速度を基準にし、文字が退出するまで保持する。
寿命の上限は16秒で、非常に長いコメントは途中で消える場合がある。重なりが完全になくなる方式ではない。
噴水は既定速度で3.6〜4.6秒の弾道とし、五つの投入口へ分散。速度設定は両方式に適用する。

通常の配布用ビルド:

```sh
cmake -S . -B build -DMIRAKURUN_DISTRIBUTION=ON
cmake --build build
```

従来機能をまとめて有効にするローカル評価用ビルド:

```sh
cmake -S . -B build/comment-evaluation -DMIRAKURUN_EVALUATION_LEGACY_COMMENTS=ON
cmake --build build/comment-evaluation
./build/comment-evaluation/mirakurun-viewer
```

従来配置は「横スクロール」→「従来の衝突回避（評価用）」を選ぶ。フラグを付けただけでは配置の初期値は変わらない。
個別のCMakeフラグは `MIRAKURUN_EVALUATION_COMMENT_LIST`、`MIRAKURUN_EVALUATION_WIDE_COMMENTS`、
`MIRAKURUN_EVALUATION_COLLISION_LAYOUT`。対応するCargo featureは上記のとおり。
評価版は `cmake --install` を拒否し、AppImage/Flatpakは `distribution` を必須にして評価機能との併用を拒否する。
`--all-features` は意図的に相反する機能を含むため使用せず、通常・評価・配布を別々に検証する。

```sh
bash scripts/test-danmaku.sh
bash scripts/test-danmaku.sh --evaluation-legacy-comments
```

通常版では従来配置専用のQML試験をskipし、評価版で同じ試験を実行する。
噴水・通常配置・サイドバー・映像矩形の試験はどちらでも実行する。
