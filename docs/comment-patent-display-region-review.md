# 映像内のコメント一覧と「別に設けられた」の追加調査

調査日: 2026-09-18。対象コードは `5f15b8d`（`feature/comment-display-modes`）。
[請求項単位の再調査](comment-patent-claim-review.md)のうち、7080382・7153786・7277651の
一覧表示領域について、映像に重ねた履歴一覧を残せるかを調べた。
本書は仕様候補の検討であり、アプリの表示・ビルド条件は変更していない。

その後、利用者の指示で通常版のサイドパネル一覧を無効化した。
現行版への対比は[一覧無効化後の差分](comment-patent-claim-review.md)を参照。
本書が検討した映像内一覧は実装していないため、その解釈問題は現行版の不充足理由に用いない。

## 結論

**映像の内側に一覧を置くことだけで、対象の要件を明確に不充足とする根拠は確認できなかった。**
反対に、その配置が当該要件を充足すると確定する資料も確認できていない。
現行版の対比結果を充足へ変更せず、映像内一覧の候補も未確定として扱う。

確認できた登録請求項は「動画表示領域とは別に設けられたコメント表示領域」を要求する。
この「別」が、画面上で動画と重ならない領域を意味するのか、重なっていても独立した
一覧表示領域を含むのかが問題になる。「映像外」という省略表現で結論を出さない。
[7080382・請求項1](https://patents.google.com/patent/JP7080382B2/ja#C1)、
[7153786・請求項1・2](https://patents.google.com/patent/JP7153786B2/ja#C1)、
[7277651・請求項1等](https://patents.google.com/patent/JP7277651B2/ja#C1)。

今回の追加資料からは、次の二つを区別できる。

- **確認できたこと:** 図面の一覧は映像の横に置かれ、公開された補正書にも別領域の一覧という要件がある。
- **確認できないこと:** その配置だけに権利範囲を限定し、映像内に重ねた一覧を除外するという出願人の説明や判断。

## 1. 明細書と図面

3件の登録公報の段落0017・0018・0020と図5を確認した。
図5では、動画の欄104、動画に重なるコメントの欄105、動画の右側の一覧112を描き分けている。
段落0020には一覧112を表示・非表示にできる説明があるが、弾幕との排他的な切り替えを定めていない。
[7080382・公報PDF](https://patentimages.storage.googleapis.com/79/a3/31/e19e99826e5bbc/JP7080382B2.pdf)、
[7153786・公報PDF](https://patentimages.storage.googleapis.com/e1/80/09/7174dedb15e3a0/JP7153786B2.pdf)、
[7277651・公報PDF](https://patentimages.storage.googleapis.com/f5/31/46/e78785b79291fa/JP7277651B2.pdf)。

**評価:** 映像と並べる一覧が具体例であることは確認できる。しかし、図5の具体的な配置を
請求項に追加し、「別」とは必ず非重複であると確定することはできない。
また、欄105は移動コメントの領域であり、一覧112と混同しない。
移動コメントを映像に重ねる記載から、一覧を重ねる場合の扱いを直接導くこともしない。

これは**取得できた時点間の比較**であり、全ての補正・意見書を取得したという意味ではない。
補正の提出日・文言は確認できたが、映像内の一覧を除外する補正理由は確認できなかった。
文言が加わった事実だけから、特定の先行技術を避けるためだった、または重畳一覧を放棄した、とは推測しない。

### 歴史資料のHTMLとPDFの差

7277651に対応するA5のPDFでは、請求項2は移動コメントを動画に重ねる限定である。
一方、取得時の[A5のHTML](https://patents.google.com/patent/JP2022122955A5/ja)の請求項2は、
登録公報と同じく文字列の並ぶ方向への移動を記載していた。
したがって、補正内容・提出日はPDF原文を基準にした。

登録公報7080382の7項、7153786の2項、7277651の19項については、PDFのページ見出し・
行番号・空白を除いた本文が、先の調査で取得したHTMLの請求項と一致した。
この歴史資料の差を理由に、現行の請求項対比まで変更していない。

## 3. 裁判資料から分かることと適用限界

### 2022-07-20 知財高裁・平成30年（ネ）第10077号

[判決全文39–41頁](https://www.courts.go.jp/assets/hanrei/hanrei-pdf-91418.pdf#page=39)では、
4734471の第1・第2表示欄について、実際の動画・コメントの表示位置や領域を基準に判断している。
論理上確保した領域だけを基準にする被控訴人の主張を採用していない。

**今回への示唆（本調査の推論）:** 同じQML親要素や描画面を使うという実装内部の共通性だけでは、
表示領域に関する説明として十分とはいえない。実際の表示状態も示す必要がある。
ただし、この判決は4734471の、動画の内外にまたがる欄などを含む別の請求項についての判断である。
今回の3件の「別に設けられた」を直接解釈した判決としては使わない。

### 2023-05-26 知財高裁・令和4年（ネ）第10046号

[判決全文](https://www.courts.go.jp/ip/vc-files/ip/2023/4n10046chizaisaishuu.pdf)の対象は6526304。
今回の3件を対象とした、映像内の一覧を除外する判断は確認できなかった。
同じドワンゴ対FC2の事件であることや関連する出願系列であることから、結論を移し替えない。

### 2025-03-03 最高裁の2判決

[令和5年（受）第14号・第15号](https://www.courts.go.jp/assets/hanrei/hanrei-pdf-93838.pdf)は4734471、
[令和5年（受）第2028号](https://www.courts.go.jp/assets/hanrei/hanrei-pdf-93839.pdf)は6526304を対象とする。
国境をまたぐプログラム提供・システム生産に関する判断であり、今回の3件の配置文言を解決する資料ではない。

上記の裁判所原文と、特許番号・対象文言による検索では、今回の3件について重畳一覧の扱いを
直接判断した裁判例を見つけられなかった。「存在しない」と断定するものではない。

## 5. 仕様候補への反映

| 仕様候補 | この追加調査での評価 |
| --- | --- |
| 映像内に半透明の履歴パネルを重ね、弾幕と切り替える | 使い勝手の候補として残す。ただし、領域の別個性と排他切り替えの解釈は未確定 |
| 動画と同じ全面の描画領域で、同じコメント描画器を静止した行表示へ切り替える | 専用パネルを作らない設計上の違いは説明できるが、同じ描画器であることだけを不充足理由にはしない |
| 通常版に履歴一覧の機能を持たせず、評価版にのみ組み込む | 通常版には一覧表示という必須構成そのものがなく、今回の3件について領域の解釈に依存しない不充足理由を作れる |

最初の2案は未実装。実装を検討する場合は、少なくとも次を仕様として固定してから再対比する。

- `Off / Moving / History` のような排他的な状態で表示方式を管理する。
- 履歴・移動コメントとも、実際の映像の矩形内に収める。黒帯やサイドバーには受信本文を出さない。
- 履歴を開く際に移動コメントの描画を終了し、閉じた際に履歴の描画を終了する。
- 一覧の自動スクロール・開閉アニメーションが文字の移動表示になるかも対象にする。
- 同じコメントを履歴と弾幕の両方で扱うという集合関係は残るものとして評価する。
- QMLの構造だけでなく、全画面・縦長・リサイズ・設定復元時の実際の表示を検証する。

これらは仕様を明確にする条件であり、守れば非侵害と認定できる条件ではない。
また、7852687の「動画表示欄の右側」という別の限定や、4734471の動画外表示の要件を、
今回の3件の「別に設けられた」と同じ意味に扱わない。

本調査によって、現行版の機能、先の対比表の結論、均等論・間接侵害の評価、
権利の満了見込みを変更していない。
