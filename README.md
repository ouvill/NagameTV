# ながめTV (NagameTV)

ながめTVは、Linuxデスクトップ環境で動作するテレビ視聴・TS録画再生アプリケーションです。Mirakurunサーバーを介した地上波・BS・CS放送の受信と、ローカルにあるMPEG-2 TS録画ファイルの再生に対応します。

7日分のEPG番組表表示、ARIB規格に準拠した字幕描画、およびNX-Jikkyoと連携した実況コメントの弾幕表示・投稿機能を備えています。

## 機能一覧

### テレビ放送の視聴
- **Mirakurun連携**: ネットワーク上のMirakurunサーバーへ接続し、放送波を受信して再生します。
- **チャンネル選択**: 地デジ・BS・CS・CATVの放送種別タブによる絞り込み、局ロゴ表示、およびカルーセル表示による選局に対応します。
- **前後選局**: ページアップ／ページダウンキーで前後のチャンネルへ順次切り替えられます。

### TS録画ファイルの再生とタイムシフト
- **ローカル再生**: ウィンドウへのドラッグ＆ドロップまたはファイル選択ダイアログから、188バイト形式のMPEG-2 TSファイルを再生します。この機能はMirakurunサーバーが未設定でも動作します。
- **シーク操作**: シークバー操作のほか、10秒戻し、30秒送り、一時停止、再開に対応します。
- **番組情報の連動**: TSストリームに含まれるメタデータ（EIT/SDT/TOT）を解析し、再生位置に合わせて番組名、詳細説明、ジャンルを表示します。
- **タイムシフト（ライブ振り返り）**: ライブ放送中の一時停止、および受信済みバッファ内の巻き戻し再生に対応します。

### 番組表（EPG）
- **週間番組表**: 複数チャンネルにわたる今日から7日分の番組一覧を表示します。
- **番組詳細**: 番組のタイトル、詳細説明、ジャンル、放送日時を確認できます。

### 実況コメント（NX-Jikkyo連携）
- **弾幕表示**: 視聴中の局に対応するNX-Jikkyoのコメントを受信し、映像上に流します。
- **表示方式**: 画面を流れる横スクロール表示と、画面下部から放物線を描いて現れるポップ表示を選択できます。
- **コメント投稿**: 専用の入力欄から実況へコメントを送信できます。自身の投稿は黄色枠で強調表示されます。
- **外観の調整**: 文字サイズ（14〜72px）、透明度、速度、影の有無を変更できます。

### 字幕と音声
- **ARIB字幕**: ARIB外字フォントを用いた地上波・BS字幕の表示と、常時縁取りオプションに対応します。
- **音声トラック切り替え**: 主音声と副音声の切り替えに対応します。
- **二重音声**: デュアルモノラル放送において、主音声のみ、副音声のみ、主副両方のステレオ出力を切り替えられます。
- **音量管理**: スライダーによる音量変更、消音、および再開時の音量維持を行います。

### 撮影と外部制御
- **画面撮影**: 表示中の字幕や弾幕コメントを含めた映像をPNG画像として保存します。
- **起動時自動再生**: 前回終了時に視聴していた局を起動時に自動で再生開始する設定を備えます。
- **多言語対応**: 日本語および英語のUI表示に対応します。
- **遠隔操作API**: 家庭内LAN上の別端末から選局や再生制御を行えるgRPC / gRPC-Web APIを搭載しています。

## 動作環境

本アプリケーションを実行するには、以下の環境が必要です。

- **OS**: Linux デスクトップ環境（X11 または XWayland）
  - 動作確認済み: Ubuntu 24.04 LTS、Ubuntu 26.04 LTS、Fedora 40以降
- **音声サーバー**: PipeWire または PulseAudio
- **Mirakurunサーバー**: ライブ放送の視聴とEPG番組表の取得に必要です。ローカルTSファイルの再生のみを行う場合は、Mirakurunサーバーを用意する必要はありません。
- **グラフィックス**: OpenGL対応GPU環境を推奨します。

## インストール

利用環境に応じて以下の3種類のパッケージ形式から選択します。

### 1. Ubuntu debパッケージ（Ubuntu 24.04 / 26.04）

APTコマンドで依存パッケージとともに導入します。

```sh
# Ubuntu 24.04 の場合
sudo apt install ./nagametv_0.1.0-1ubuntu24.04_amd64.deb

# Ubuntu 26.04 の場合
sudo apt install ./nagametv_0.1.0-1ubuntu26.04_amd64.deb
```

インストール後はアプリケーションランチャーまたは端末から `nagametv` で起動します。詳細な仕様とパッケージのビルド手順は [debの手順](docs/deb.md) を参照してください。

### 2. Flatpakパッケージ

ディストリビューションを選ばず、隔離された環境で実行する場合に適しています。

```sh
flatpak install --user ./nagametv-0.1.0-x86_64.flatpak
flatpak run io.github.ouvill.nagametv
```

初回起動時に必要なランタイムが自動で取得されます。詳細は [Flatpakの手順](docs/flatpak.md) を参照してください。

### 3. AppImageパッケージ

パッケージのインストールを行わず、単一ファイルから直接実行する場合に適しています。

```sh
chmod +x ./nagametv-0.1.0-x86_64.AppImage
./nagametv-0.1.0-x86_64.AppImage
```

ビルド方法やglibcの互換要件は [AppImageの手順](docs/appimage.md) を参照してください。ソースコードから直接ビルドする場合は [開発・ビルド・診断ガイド](docs/development.md) を参照してください。

## 基本操作

### 1. 初回設定（Mirakurunへの接続）
起動すると「Mirakurun に接続」画面が表示されます。稼働中のMirakurunサーバーのURL（例: `http://192.168.1.100:40772`）を入力し、「接続する」を選択します。接続が確認されると設定が保存され、選局画面へ進みます。接続先は後から設定画面の「接続」項目で変更できます。

### 2. 放送局の選択
画面下部のチャンネルボタン、または `S` キーでチャンネル一覧を開きます。地デジやBSなどのタブで表示を絞り込み、カードをクリックして選局します。視聴中は `PgUp` / `PgDown` キーにより前後の局へ順次切り替えることもできます。

### 3. 番組表の表示
`G` キーまたは番組表ボタンにより、7日分のEPG番組表を表示します。放送視聴中だけでなく、再生停止中やオフライン時でも確認できます。

### 4. TS録画ファイルの再生
TSファイルをウィンドウ内へドラッグ＆ドロップするか、`Ctrl + O` キーでファイル選択ダイアログを開きます。再生中は `Space` キーで一時停止と再開、左右の矢印キーで10秒戻し・30秒送りが可能です。ライブ視聴に戻る場合は右上のテレビボタンを押すか、チャンネル一覧から局を選びます。

### 5. 実況コメントの表示と投稿
コメント機能は初期設定で有効です。弾幕の表示切り替え、表示形式（横スクロール／ポップ）、文字サイズ、透明度は設定画面の「コメント」または再生バーの「再生設定」から変更できます。`C` キーを押すと画面下部に投稿欄が現れ、テキストを入力して `Ctrl + Enter`（設定によりEnter単体にも変更可能）で送信します。

### 6. 画面の撮影
再生バーのカメラボタン、または `Ctrl + S` キーを押すと、その時点の映像がPNG画像として保存されます。表示中の字幕や弾幕コメントも画像に含まれます。初期設定の保存先は `~/ピクチャ/nagametv/` です。保存先フォルダーは設定画面の「表示」項目で変更できます。

## キーボードショートカット

| キー | 動作 | 備考 |
| :--- | :--- | :--- |
| `S` | チャンネル一覧の開閉 | 放送局カルーセルを表示 |
| `C` | コメント投稿欄を開く | 入力欄へフォーカスを移動 |
| `G` | 番組表の開閉 | 7日分のEPG番組表を表示 |
| `Space` | 再生 ／ 一時停止 | 録画再生中およびタイムシフト再生中に有効 |
| `←` / `→` | 10秒戻る ／ 30秒進む | 録画再生中およびタイムシフト再生中に有効 |
| `PgUp` / `PgDown` | 前 ／ 次のチャンネルへ選局 | ライブ視聴時に有効 |
| `Ctrl + S` | スクリーンショットを保存 | 字幕・弾幕を含めてPNG保存 |
| `Ctrl + O` | TS録画ファイルを開く | 初回接続画面でも利用可能 |
| `F11` | 全画面表示の切り替え | 映像領域のダブルクリックでも切り替え可能 |
| `Escape` | パネルを閉じる ／ 全画面解除 | 最前面のポップアップやパネルを順次閉じる |

コメント入力欄などの文字入力中は、文字キーによる画面切り替えやシーク操作は誤入力を防ぐため自動的に無効化されます。

## 設定の保存場所

設定した接続先URL、最後に選択していた局、音量、各種表示設定は終了時に保存され、次回起動時に復元されます。

- **ネイティブ版・AppImage版**: `~/.config/nagametv/`（`$XDG_CONFIG_HOME/nagametv/`）
- **Flatpak版**: `~/.var/app/io.github.ouvill.nagametv/config/nagametv/`

「設定」→「接続」にある「起動時に自動再生する」を有効にすると、起動時に前回の選択局を自動で再生開始します。

## 遠隔操作API

家庭内LAN上の別端末から本アプリケーションを操作できる gRPC / gRPC-Web API（`viewer.v1.PlayerService`）を搭載しています。

- 選局、再生・停止、音量調整、消音、字幕切り替え、および再生状態の購読（WatchState）に対応します。
- 「設定」→「リモート操作」から有効化できます（初期ポート: `50051`）。
- 仕様と設定方法は [遠隔操作APIドキュメント](docs/remote-control.md) および [Protocol Buffers定義](docs/api/remote-control.md) を参照してください。
